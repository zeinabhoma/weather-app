# Weather App

A simple weather application built with **HTML**, **CSS**, and **JavaScript**.  
This app fetches real-time weather data using the **OpenWeatherMap API**, and displays the current weather based on the user’s input city.

---

## Technologies & Tools

- HTML
- CSS
- JavaScript
- OpenWeatherMap API
- Bootstrap

## Getting Started (Local Setup)

1. Clone the repository:

```bash
git clone https://github.com/zeinabhoma/weather-app.git
 ```

2. Navigate to the project folder and install dependencies:

```bash
cd weather-app
```

3. Open the index.html file in your browser

---

##  Features

- Search for weather by city name
- Real-time weather data using OpenWeatherMap API
- Display of temperature, weather condition, and city name
- No frameworks — built with pure JavaScript
